# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/eliangilsierra/taskflow/security/advisories/new)
instead, and include:

- a description of the issue and its impact,
- steps to reproduce it,
- any suggested fix.

You can expect an acknowledgement within a few days. Once a fix is available, the report will be
disclosed together with the release that contains it.
